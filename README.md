# ADHDers Club Website

A responsive and user-friendly website built for the ADHDers Club to showcase its mission, team, and ways to get involved.

## 🚀 Overview

This project is a multi-page website designed to:

* Introduce the ADHDers Club
* Highlight the team and community
* Provide ways for users to connect and join

The website focuses on clean design, accessibility, and simple navigation.

## 🛠️ Tech Stack

* **HTML5** – structure and content
* **CSS3** – custom styling and layout
* **Tailwind CSS** – utility-based styling (used selectively)
* **JavaScript** – interactivity
